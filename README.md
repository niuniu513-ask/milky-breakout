# 奶蛙打砖块

零外部依赖的 Canvas 小游戏。下载 `index.html` 后用浏览器打开即可离线游玩。

## 操作

- 鼠标、触摸拖动或左右方向键移动挡板。
- 点击游戏区域或按空格发射；磁力吸住后再次点击或按空格释放。
- P / Esc 或右上角按钮暂停；切走页面会自动暂停。
- 菜单和暂停页均可切换音效、热闹特效，偏好自动保存。

## 关卡与进度

100 关分为十个主题章节，通关后进入无尽模式。关卡固定生成，重试时图案一致。每关开局保存检查点，过关时立即保存下一关。
再次打开页面、返回主菜单或失败重试，默认继续已保存的关卡，不要求从第一关重打。
续玩保留之前关卡累积的分数、解救数与进化形态，当前关卡从开局恢复，生命补满四颗。

存档及排行榜保存在当前浏览器的本地存储中，不上传服务器；换浏览器、换访问地址或清除网站数据后无法沿用原存档。浏览器禁止存储时仍可游玩，但进度仅在当前页面保留。

## 验证

运行离线逻辑与存储回归检查（需要 Node.js，无 npm 依赖）：

```powershell
node tests/regression.cjs
```

`tests/browser-regression.js` 可在独立测试浏览器中执行，覆盖关卡初始化、爆炸连锁去重、自动暂停、跨关清理、无尽存档恢复和最后奶块过关优先级。它会修改测试页面的游戏状态和本地进度，请勿在实际游玩页面运行。

## 奶娃装饰与反馈

奶娃家族保留在奶块、解救动画和观众席中，并提供奶珠拖尾、击碎飘分和暴走提示。已移除助阵蓄力条、扫荡奶波、护底和定时自动攻击；激光仍是玩家接取的道具。热闹特效开关可关闭拖尾、弹幕、震屏与彩虹背景。

## 休闲难度与全链路检查

挡板宽度为 116，基础球速为 280，并缓慢增长至最高 450；不随游玩时长加速。前 100 关无钢砖，只掉落有益道具，前 15 关普通砖均为一击即碎。每关恢复四颗心，过关依靠奶珠碰撞与拾取道具。

`tests/campaign-regression.js` 覆盖全部 100 关的布局、速度上限、重试一致性、检查点还原、实际奶珠碰撞清砖、下一关按钮与第 101 关衔接，另检查道具、死亡排行、暂停和菜单续玩。与基础和存储回归共 747 项检查。自动检查验证流程正确性，不等同于真人难度测评。
