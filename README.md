# 奶蛙打砖块

零外部依赖的 Canvas 小游戏。下载 `index.html` 后用浏览器打开即可离线游玩。

## 操作

- 鼠标、触摸拖动或左右方向键移动挡板。
- 点击游戏区域或按空格发射；磁力吸住后再次点击或按空格释放。
- P / Esc 或右上角按钮暂停；切走页面会自动暂停。
- 菜单和暂停页均可切换音效、热闹特效，偏好自动保存。

## 关卡与进度

100 关分为十个主题章节，通关后进入无尽模式。关卡固定生成，重试时图案一致。每关开局保存检查点，过关时立即保存下一关。
再次打开页面、返回主菜单或失败重试，默认继续已保存的关卡，不要求从第一关重打。
续玩保留之前关卡累积的分数、解救数与进化形态，当前关卡从开局恢复，生命补满四颗。

存档及排行榜保存在当前浏览器的本地存储中，不上传服务器；换浏览器、换访问地址或清除网站数据后无法沿用原存档。浏览器禁止存储时仍可游玩，但进度仅在当前页面保留。

## 验证

运行离线逻辑与存储回归检查（需要 Node.js，无 npm 依赖）：

```powershell
node tests/regression.cjs
```

`tests/browser-regression.js` 可在独立测试浏览器中执行，覆盖关卡初始化、爆炸连锁去重、自动暂停、跨关清理、无尽存档恢复和最后奶块过关优先级。它会修改测试页面的游戏状态和本地进度，请勿在实际游玩页面运行。

## 奶娃装饰与反馈

奶娃家族保留在奶块、解救动画和观众席中，并提供奶珠拖尾、击碎飘分和暴走提示。已移除助阵蓄力条、扫荡奶波、护底和定时自动攻击；激光仍是玩家接取的道具。热闹特效开关可关闭拖尾、弹幕、震屏与彩虹背景。

## 关卡节奏、道具与全链路检查

挡板宽度为 116，主线球速按章节与关内节奏配置，限制在 280–440；不随游玩时长加速。100 关采用不同布局，每章按教学、练习、爽感、组合、挑战、章末组织。第 12 关起引入两击砖，第 32 关起引入爆炸砖，第 62 关起引入三击砖；主线无钢砖和移动砖，每关恢复四颗心。

道具依次在第 2/4/12/22/32/52 关解锁加宽、减速、磁力、分裂、激光、穿透，解锁关固定安排教学掉落。主线仅有益卡，每关预算 2–6 张（第 1 关不掉落），连击奖励和教学卡也计入预算。中文卡面和接取提示说明用途；同类效果刷新时间，激光与穿透互相替换，分裂最多五球。

加宽为 10 秒、1.35 倍宽度，减速为 8 秒、0.75 倍球速，磁力 8 秒，激光 6 秒，穿透 5 秒。无尽模式才有风险卡，缩板在 8 秒后恢复。

`tests/campaign-regression.js` 覆盖全部 100 关的布局、速度上限、重试一致性、检查点还原、实际奶珠碰撞清砖、下一关按钮与第 101 关衔接，另检查道具、死亡排行、暂停和菜单续玩。`tests/design-regression.js` 另覆盖分阶段解锁、掉落预算、教学保底、强卡互斥、效果到期与穿透单次接触伤害。与基础和存储回归共 1178 项检查。自动检查验证流程正确性，不等同于真人难度测评。
