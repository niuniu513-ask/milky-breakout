# 奶蛙打砖块

零外部依赖的 Canvas 小游戏。下载 `index.html` 后用浏览器打开即可离线游玩。

## 操作

- 鼠标、触摸拖动或左右方向键移动挡板。
- 点击游戏区域或按空格发射；磁力吸住后再次点击或按空格释放。
- P / Esc 或右上角按钮暂停；切走页面会自动暂停。
- 菜单和暂停页均可切换音效、热闹特效，偏好自动保存。

## 关卡与进度

100 关分为十个主题章节，通关后进入无尽模式。关卡固定生成，重试时图案一致。每关开局保存检查点，过关时立即保存下一关。
再次打开页面、返回主菜单或失败重试，默认继续已保存的关卡，不要求从第一关重打。
续玩保留之前关卡累积的分数、解救数与进化形态，当前关卡从开局恢复，生命补满五颗。

存档及排行榜保存在当前浏览器的本地存储中，不上传服务器；换浏览器、换访问地址或清除网站数据后无法沿用原存档。浏览器禁止存储时仍可游玩，但进度仅在当前页面保留。

## 验证

运行离线逻辑与存储回归检查（需要 Node.js，无 npm 依赖）：

```powershell
node tests/regression.cjs
```

`tests/browser-regression.js` 可在独立测试浏览器中执行，覆盖关卡初始化、爆炸连锁去重、自动暂停、跨关清理、无尽存档恢复和最后奶块过关优先级。它会修改测试页面的游戏状态和本地进度，请勿在实际游玩页面运行。

## 奶娃助阵

每关开局赠送一次护底；每解救 12 只伙伴或发射后每过 22 秒，会自动触发一次奶波扫荡，对沿途普通奶块造成一次伤害（钢砖不受影响）。同时获得一次护底：全部球掉落时免扣生命，重新发射即可。护底不叠加，助阵蓄力和护底随关卡重置。

奶娃家族会出现在奶块、解救动画和扫荡队伍中；新增奶珠拖尾、击碎飘分与集结提示。热闹特效开关可关闭拖尾、弹幕、震屏与彩虹背景，助阵玩法保持可用。

## 休闲难度与全链路检查

挡板宽度由 92 增至 132，基础球速由 330 降至 240，并缓慢增长至最高 380；不随游玩时长加速。前 100 关无钢砖，只掉落有益道具，前 15 关普通砖均为一击即碎。每关恢复五颗心，开局送护底，35 秒后剩余不超过三块时赠送激光收尾。

`tests/campaign-regression.js` 覆盖全部 100 关的布局、速度上限、重试一致性、检查点还原、实际助阵扫荡、下一关按钮与第 101 关衔接，另检查道具、死亡排行、暂停和菜单续玩。与基础和存储回归共 751 项检查。自动检查验证流程正确性，不等同于真人难度测评。
